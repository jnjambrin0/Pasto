# Pasto 1.0.1

Fixes and polish after the first release.

- **Search no longer quits Pasto**: typing in the search field could close the app. Fixed.
- **Faster with a large history**: the list, captures, searches and clean-ups stay quick with hundreds of thousands of clips, and Pasto uses far less memory for large copies.
- **Your shortcuts on a new Mac**: Pasto now sets ⇧⌘V and ⇧⌘C on first launch, or the nearest free alternatives, and tells you if another app takes a shortcut later.
- **Spanish**: the whole app is available in Spanish.
- **Privacy**: Pasto no longer hands the text of your clips to system search, link previews are not fetched from local or private addresses, and Pasto's files can only be read by you.
- **Accessibility**: VoiceOver reads cards, tabs and controls, cards have actions, and Reduce Motion and Increase Contrast are respected.
- **Help**: a Help menu with getting started, keyboard shortcuts and *Report a Problem…*, which sends nothing by itself.
- **Recovery**: if the database cannot be opened, Pasto offers to set it aside and start fresh instead of quitting.
- Many small fixes to tabs, the toolbar, previews, the Stack and Settings, including the feature's name: it is now simply *Stack*.

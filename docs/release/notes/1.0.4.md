# Pasto 1.0.4

A new look, and Pasto is now open source.

- **A new icon**: three frosted cards rising from the grass.
- **A new menu bar icon**: Pasto's tile with two leaves cut out of it, sized like the system's own icons beside it. The Stack's title shows it too.
- **The Stack stays on screen**: with three or more items the panel could grow past the bottom of the screen and hide its last rows. It now moves up as it grows.
- **Open source**: Pasto's code is public under the MIT license at github.com/jnjambrin0/Pasto.
- *Help › Report a Problem…* now writes to hello@jnjambrino.com.

# Pasto 1.0.2

Speed and safety for very large clips.

- **Large copies use less memory**: capturing a big image, file or text now peaks at about twice its size, and saving it is several times faster.
- **Pasting large images no longer stalls**: a very large image is prepared in the background instead of freezing Pasto for seconds.
- **Search stays instant**: indexing reads only what it needs, source names are looked up much faster, and a search the system leaves unanswered now ends by itself.
- **Link previews**: Pasto fetches the page itself, reads only its head, and refuses redirects to local or private addresses.
- **Less work in the background**: card dates stop updating while the panel is hidden, and the text recognition queue no longer rewrites settings after every image.
- Coming back to the history tab is immediate.
